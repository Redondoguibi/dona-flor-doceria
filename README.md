# Dona Flor Doceria — demonstração independente

Este repositório contém **uma proposta visual independente e não oficial** de reformulação do site da Dona Flor Doceria, em Santos (SP). Não representa a empresa, não possui vínculo oficial com ela e não deve ser usado como site comercial sem autorização.

## Visualização pelo GitHub Pages

Após habilitar **Settings → Pages → Deploy from a branch → main → /(root)**, a versão estática estará disponível em:

https://redondoguibi.github.io/dona-flor-doceria/

Os arquivos estão na raiz para facilitar o GitHub Pages; o arquivo `index.html` é a página inicial.

## O que esta versão contém

- Página responsiva em HTML, CSS e JavaScript;
- Galeria, catálogo com busca e filtros;
- Cardápio de **demonstração**, arquivado de 09/10/2026 a 14/10/2026;
- Contatos, localização e informações históricas sujeitas à confirmação da empresa.

## Limites importantes

- **Não é o site oficial.** Produtos, preços, fotos, marca, endereços e telefones dependem de verificação e autorização.
- O GitHub Pages hospeda apenas arquivos estáticos. **O painel privado de edição e o armazenamento R2 do projeto @Sites não fazem parte desta publicação.**
- Alterações em `cardapio.json` exigem nova publicação do repositório. Nenhuma atualização do @Sites é sincronizada automaticamente.
- Não há compra, pagamento, formulário, login ou pedido online.
- O projeto mantém a marcação `noindex,nofollow` e o `robots.txt` com bloqueio de rastreamento enquanto for somente uma demonstração.
- GitHub Pages é para mostrar o projeto, não para operar o site comercial definitivo da doceria.
